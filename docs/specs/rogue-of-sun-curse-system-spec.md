# ROGUE OF SOL 呪い・解呪仕様

## 1. 目的と実装位置

本資料は、装備品に付与される永続的な呪いと、その鑑定・装備・解除規則を定義する。

呪いはキャラクターへ付く一時状態異常ではなく、武器・防具などの**アイテム個体が保持する状態**として実装する。開発計画上は、装備と未鑑定の基盤が成立した後の`Phase 17.5：呪い・解呪`に置き、敵固有能力、通常敵ドロップ、カードより先に完成させる。

```text
装備・未鑑定の基盤
→ Phase 17.5 呪い・解呪
→ Phase 18 敵固有能力
→ Phase 18.5 敵ドロップ・戦利品
→ Phase 19 カード
```

## 2. 基本ルール

- 呪い状態は同じ種類の装備でも個体ごとに異なる。
- 呪われた装備は使用不能品にせず、欠点を受け入れれば装備として利用できる。
- 呪いの有無は未鑑定情報に含め、未鑑定中は名称や説明から判別できない。
- 鑑定済みなら、装備する前に呪いの有無と判明済みの不利益を確認できる。
- 未鑑定の呪い装備を装着した場合、その時点で少なくとも「呪われていること」と装備解除不能を開示する。
- 呪いはフロア移動、時間経過、LIFE回復、通常の状態異常回復では解除されない。
- 呪いの解除後は同一個体を通常装備として保持し、基礎性能、強化値、ランクなど他の個体情報を維持する。
- 呪いによる補正は基礎値を書き換えず、装備補正の計算段階で別要因として適用する。

## 3. 初期実装の呪い系統

初期実装は次の3系統に限定する。1個体へ複数系統を同時付与するかは、Phase 17.5開始時に決定する。

| 系統 | 必須効果 | 例 | 初期実装上の制限 |
|---|---|---|---|
| 束縛 | 装備すると解除・交換できない | 武器交換不能、防具解除不能 | アイテム使用や通常行動までは禁止しない |
| 劣化 | 本来より装備性能が低下する | 威力、防御、最大LIFE、最大SOLなどの低下 | 基礎値を破壊せず呪い補正として保持する |
| 災厄 | 装備中に確率的または条件付きの不利益が起きる | 攻撃失敗、SOL消費増加など | 完全行動不能、毎ターン大ダメージは初期対象外 |

初期版では、拾った時点で冒険継続がほぼ不可能になる極端な効果を採用しない。具体的な低下量、発動率、装備種別ごとの候補は数値調整対象とする。

## 4. 装備・所持品操作

### 4.1 装備

- 鑑定済みの呪い装備を選ぶ場合、通常の装備確認に呪い警告を追加する。
- 未鑑定品は通常どおり装備できる。呪いだった場合は装備成立後に判明する。
- 装備した瞬間から束縛と各種不利益を適用する。
- 呪い判明のためだけに追加ターンを発生させない。装備行動の既存ターン規則に従う。

### 4.2 解除・交換

- 束縛中の装備は、通常の「外す」と別装備への「交換」を拒否する。
- 拒否された操作でターンを消費するかは、既存の失敗操作規則へ統一する。
- 呪われていない別スロットの装備操作は妨げない。

### 4.3 置く・捨てる・売る

- 装備中かつ束縛中の個体は、置く、捨てる、投げる、売る、素材化など、装備解除を迂回する操作に使用できない。
- 未装備の呪い品は原則として置く、捨てる、売ることができる。
- 未鑑定中の売却価格や店側の表示は、売買要素を実装するフェーズで決定する。

## 5. 鑑定と表示

アイテム個体は最低限、次の情報を分離して保持する。

- 呪いの有無
- 呪い系統または効果ID
- 呪いの強度
- 呪いがプレイヤーへ判明済みか
- アイテム本体の鑑定状態
- 解呪済みかどうか

UIでは次を満たす。

- 未判明の呪いを名称、色、並び順、比較値から漏らさない。
- 判明後は一覧、詳細、装備比較で呪いを識別できる。
- 劣化の比較表示は、通常性能と呪い適用後の実効性能を混同させない。
- 束縛によって拒否された操作には、解除不能の理由をメッセージ表示する。

## 6. 解呪

初期の携帯可能な解呪手段は、大アルカナ「節制」とする。別名の解呪カードは追加しない。

- 節制は、呪われた装備品を通常品へ戻す。
- 解呪はアイテム本体を別アイテムへ置換せず、同一個体の呪い状態だけを解除する。
- 装備中の束縛品を解呪した場合、その場では装備状態を維持し、以後は通常どおり解除・交換できる。
- 対象が1個か装備中全品かは、Phase 19開始前にカード仕様と合わせて確定する。
- 解除対象が存在しない場合、節制は原則として使用不成立とし、消費もターン経過も起こさない。

施設・特殊地点による解呪は将来候補とし、Phase 17.5の必須実装には含めない。

## 7. 生成・ドロップとの接続

- 床生成と敵ドロップは、装備個体を生成した後に呪い抽選を行える共通処理を使う。
- 同一seed・同一操作列では、同じ個体に同じ呪い結果が付く。
- 進行用アイテム、固定報酬、呪い対象外カテゴリには呪いを付与しない。
- 通常敵が落とす呪い装備の率は敵ドロップ仕様で直接固定せず、共通アイテム生成設定を参照する。
- Rランクや特殊報酬を呪い対象にするかは、装備報酬設計時の未確定事項とする。

## 8. telemetry

最低限、次をラン単位で記録する。

- 呪い装備の生成数、発見数、取得数
- 未鑑定のまま装備した回数
- 呪い系統別の装備回数
- 束縛による操作拒否回数
- 呪い装備中の戦闘数・フロア突破数
- 節制による解呪回数と対象数
- 呪い装備を未装備のまま捨てた回数

## 9. 必須テスト

- 同種装備でも個体ごとに呪い状態を保持できること
- 未鑑定中に呪い情報が表示・比較・並び順から漏れないこと
- 装備後に呪いが判明し、効果が即時適用されること
- 束縛中は解除、交換、投擲、売却などの迂回操作ができないこと
- 未装備の呪い品は通常規則に従って置く・捨てることができること
- 劣化が基礎値を破壊せず、実効値だけへ反映されること
- 災厄の抽選がseed付きPRNGで決定的であること
- フロア移動や通常回復で呪いが解除されないこと
- 節制で同一個体の呪いだけが解除されること
- 装備中の品を解呪しても勝手に装備解除されないこと
- 状態異常の解除処理が呪いへ誤作用しないこと
- 既存の装備、未鑑定、死亡、ターン処理を壊さないこと

## 10. Phase 17.5で決める事項

- 1個体に付く呪い系統数
- 束縛を全呪い装備の共通効果にするか、独立系統にするか
- 劣化の対象能力と低下量
- 災厄の候補、発動条件、発動率
- 失敗した解除・交換操作のターン消費
- 鑑定と「呪いだけ判明」の状態を分けるか
- 床落ち装備と敵ドロップ装備の呪い率
- Rランク・特殊報酬へ呪いを付与するか

これらを除き、呪いをアイテム個体の永続状態として扱うこと、束縛・劣化・災厄の3系統、節制による解呪は本資料の内容で固定する。
