# ROGUE OF SOL カード効果仕様

## 1. 目的

本資料は、『続・ボクらの太陽』の大アルカナを基準としたカードの効果と、`ROGUE OF SOL`向けの置換規則を定義する。

Phase 20では、通常使用する16種類と、所持中に自動発動する「審判」1種類の合計17種類を実装対象とする。「愚者」は対象外とする。

## 2. 共通仕様

- カードは巻物相当の消耗品として扱う。
- 通常使用カードは、使用成立時に1枚消費し、1ターン経過する。
- 封印状態では通常使用できない。
- 使用処理そのものが成立するカードは、その時点で有効な効果が得られなくても使用できる。HP・SOLが最大、部屋や使用者へ自動適用する効果の作用対象となる敵・状態異常等がないなど、結果として状態変化が0になる場合も、カードを1枚消費し、未鑑定なら鑑定し、1ターン経過する。
- 封印中、未所持、古い選択情報、必須入力・必須対象が未確定、対象選択の取消など、使用処理を開始または完了できない場合だけ使用不成立とする。使用不成立時は効果・消費・鑑定・ターン進行・RNG消費をすべて行わない。
- 効果が得られなかったまま使用成立した場合は、「SOLは回復しなかった」「対象となる敵はいなかった」など、状態変化が0だったことをログまたはUIで明示する。
- 未鑑定時はカード名と詳細効果を表示しない。
- 鑑定状態はカード用に新設する鑑定機構（Phase 20.0b）に従う。この機構はrun内で共有され、フロア移動後も保持する。Phase 24で全item向けに拡張する際も、この機構自体は再実装せず流用する。
- 鑑定契機：通常使用カードは使用処理が成立した時点で、そのカード種別を鑑定済みにする。有効な状態変化が0でも使用成立なら鑑定する。床落ち・開始所持・敵ドロップによる取得や、使用不成立では鑑定しない。審判は自動発動が成立した時点で鑑定済みにする。一度鑑定した種別は同一run内で未鑑定へ戻らない。
- 封印契機：封印状態は既存の状態異常付与経路（罠、敵の特殊攻撃等）から付与される一時状態とし、通常使用コマンドの選択自体を無効化する。持続ターン数と解除条件は罠・敵ごとの個別仕様に従う。封印中でも所持・鑑定状態の表示は妨げない。
- カードは床落ちテーブルと敵ドロップテーブルへ登録できるデータ構造にする。
- Phase 20では全17種のランダム床出現と敵ドロップを無効のまま維持し、効果実装と出現バランスを分離する。
- 出現テーブルへのproduction接続は全カード効果完成後、Phase 21完了後に着手する番号未定の独立工程で行う。
- production接続後は全17種を1階から出現可能とし、カード固有の解禁階層を設けない。
- カードの出やすさは他の通常アイテムと共通の`C / B / A / S`で管理する。カードカテゴリ当選後にレアリティを固定weightで抽選し、そのレアリティに属するカードから本体を抽選する。
- カードのレアリティ分布は階層によって変えず、同一レアリティ内のカードは原則として均等抽選する。
- カードには強化値・呪い等の生成時状態を付与せず、通常生成の状態抽選を省略する。
- 同一カードおよび永続成長カードの複数出現を制限せず、run単位の出現上限も設けない。
- 所持状況、直前の出現結果、連続未出現回数などによる動的補正、最低保証、天井は設けない。
- 「現在の部屋」は9×7のカメラ表示範囲ではなく、ダンジョン生成上の部屋領域を指す。
- 部屋外で部屋対象カードを使った場合の対象は、原則として使用者のみ、または効果なしとし、カードごとに明記する。
- 効果演出中に追加ターンを進めない。
- ダメージ量、回復量、継続ターン数、装備の強化上限はPhase 20で必要な仮値を設定し、Phase 27で最終調整する。出現率はPhase 21完了後の番号未定の独立工程で仮決定する。
- LIFEとSOLは交換可能な対の資源として、ともに初期最大値15、開始時満タンとする。
- カラダによる最大LIFE上昇とココロによる最大SOL上昇には同じ係数を使用し、両資源の桁と成長幅を同程度に保つ。

### 月・太陽の装備強化規則

- 月は防具だけ、太陽は武器だけを対象とする。
- 対象は装備中の1個に固定する。所持中で未装備の同種装備は対象外とし、対象選択UIを介さず即座に対象を確定する。
- 武器の強化値は既存の与ダメージ計算、防具の強化値は既存の防御計算へ加算する。
- 強化によってDPの現在値を回復せず、最大DPも増加させない。
- 呪われた装備も強化できるが、呪いは解除されない。
- アクセサリー、進行用アイテム、カード、その他の装備外アイテムは対象外とする。
- 対応する種別（月なら防具、太陽なら武器）を何も装備していない場合は使用不成立とし、カードを消費せず、ターンも進めない。
- 強化上限に達した装備は対象にできない。装備中の対象が強化上限に達している場合は使用不成立とする。
- 強化上限はPhase 20.0cで装備個体構造を実装する際に仮値を置き、装備全体の調整時に再検討する。
- 強化値は装備個体（Phase 20.0cのequipment instance）が保持するため、装備解除・再装備を経ても値を保持する。星による同カテゴリ変換が発生した場合、変換後の新しい個体はrefineLevelを引き継がない（変換は新規個体の生成として扱う）。

### 星のアイテム変換規則

- 対象選択はPhase 20.0dの対象選択基盤を用い、所持品一覧から1個選択する。
- すべてのカードを変換対象から除外する。進行用アイテム・固定品・その他の対象外品も選択できない。
- 変換候補は「選択した対象と同カテゴリ（consumable/weapon/armor）」に属する通常アイテムから、すべてのカード、進行用アイテム、固定品、その他の対象外品、選択した対象と同一のItemIdを除いたものとする。星によってカードの希少度を迂回できない構造にする。
- 除外後の変換候補が0種類なら使用不成立とし、カードを消費せず、ターンも進めない。候補が1種類だけなら、その1種類への変換を成立させる。2種類以上ならseed付きPRNGで抽選する。
- 変換対象が装備個体（武器・防具）の場合、変換後は新規個体として生成する。refineLevel・呪い状態・呪い判明状態は引き継がない（変換前の個体は消滅する）。
- 変換対象が装備中の個体だった場合、変換後の新規個体を同じスロットへ自動的に装備する。

### 節制の対象選択規則

- 対象選択はPhase 20.0dの対象選択基盤を用いる。
- 対象は呪いが判明済みの装備個体（装備中・所持中を問わない）から1個選択する。
- 呪われていない個体と、呪いがまだ判明していない個体は選択候補に含めない。
- 選択候補が1個もない場合は使用不成立とし、カードを消費せず、ターンも進めない。

### Phase 20の最小呪いループ

- Phase 20.0c以降に床生成される武器・防具個体は、seed付きPRNGにより仮確率で呪われる。仮確率はPhase 20.0cで設定し、Phase 27で再調整する。
- 呪い状態と呪い判明状態は別々の個体属性として保持する。呪いは装備解除やフロア移動を経ても残る。
- 呪われた装備個体を装備した時点で、その個体の呪いが判明する。
- 呪いが判明した装備中個体は、通常操作では解除も別装備への交換もできない。
- 節制で解呪すると呪い状態を解除し、通常の解除・交換が可能になる。所持中で呪いが判明済みの個体も節制の対象にできる。
- 星で変換した装備は新規個体として扱い、変換前の呪い状態と呪い判明状態を引き継がない。
- Phase 24では、敵・罠・追加の生成条件などによる呪い付与、一般アイテム向け鑑定、DP・装備ランクとの接続を追加する。Phase 20で導入した個体属性は再実装しない。

### 吊るされた男の交換規則

使用前の現在LIFEを`L`、現在SOLを`S`とする。

```text
使用後LIFE = min(S, 最大LIFE)
使用後SOL  = min(L, 最大SOL)
```

最大値を超えた分は消滅し、交換前の比率ではなく整数値そのものを交換する。LIFEとSOLの初期最大値と成長尺度を揃えるのは、この交換を通常のプレイ判断として成立させるためである。

## 4. 自動発動カード

| ID | カード | 発動条件 | 効果 | 消費・ターン |
|---|---|---|---|---|
| `judgement` | 審判 | 所持中にLIFEが0になった瞬間 | LIFEを最大値まで回復し、死亡を取り消す | 1枚自動消費。追加ターンは発生しない |

### 審判の処理規則

- 通常使用コマンドには表示しない。
- インベントリには所持品として表示する。
- LIFEが0になった原因を問わず、通常の死亡確定より先に発動判定を行う。
- 複数枚所持していても、1回の死亡判定につき1枚だけ消費する。
- 審判を1枚以上所持している場合、1枚消費してLIFEを全回復する。
- 所持していない場合は通常どおり死亡する。
- 死神との組み合わせでは、SOL全回復後に審判が発動し、LIFEも全回復する。

### 死神＋審判の処理順

1. 死神を使用し、死神を消費する。
2. LIFEを0にする。
3. SOLを最大値まで回復する。
4. LIFE 0による死亡判定に入る。
5. 審判を所持していれば1枚消費する。
6. LIFEを最大値まで回復し、死亡を取り消す。
7. 死神使用分の1ターンだけを経過させ、冒険を継続する。
8. 審判を所持していなければ死亡を確定する。

## 5. 対象外

- 愚者
- カード固有の新規召喚ユニット
- 月光虫、太陽虫、暗黒虫そのものの実体化
- カード専用の新ステータス
- Phase 20時点での最終的な数値バランス

## 6. データ要件

各カード定義は最低限、次の情報を持つ。

- 一意なID
- 表示名
- 未鑑定表示名
- 使用方式（通常使用／自動発動）
- 対象範囲
- 使用可能条件
- 消費条件
- ターン消費
- 効果処理ID
- レアリティ（`C / B / A / S`）
- 床落ち可否
- 敵ドロップ可否
- telemetry用カテゴリ

カード固有の抽選はゲーム本体と同じseed付きPRNGを使用し、同一seed・同一操作列で同じ結果になること。

## 7. 必須テスト

- 通常使用16種の効果、消費、ターン経過
- 封印中に通常使用できないこと
- 有効な状態変化が0でも使用処理そのものが成立する場合は、消費・鑑定・1ターン進行が行われること
- 使用不成立時は効果・消費・鑑定・ターン進行・RNG消費がすべて発生しないこと
- 効果が得られなかった使用成立時に、その旨をログまたはUIで確認できること
- 未鑑定カードから真名と効果が漏れないこと
- 床落ち・開始所持・敵ドロップで取得しただけでは鑑定されないこと
- 通常使用カードは使用処理の成立時に鑑定され、有効な状態変化が0でも鑑定される一方、使用不成立では鑑定されないこと
- 審判は自動発動成立時に鑑定されること
- 永続上昇値がフロア移動後も維持されること
- 運命の輪が4能力すべてを抽選対象に含むこと
- 恋人がSOL最大時にも使用でき、SOLを変化させずに1枚消費・鑑定・1ターン進行すること
- 吊るされた男の最大値超過切り捨て
- 初期状態のLIFEとSOLがともに15であり、そのまま交換できること
- カラダとココロへ同数のポイントを割り振った場合、最大LIFEと最大SOLが同じ幅で増えること
- 死神が審判なしでは死亡すること
- 死神＋審判でSOLとLIFEが全回復すること
- 通常ダメージ、塔、自傷的効果によるLIFE 0でも審判が発動すること
- 審判が1回につき1枚だけ消費され、追加ターンを発生させないこと
- 床生成される装備個体の呪い付与がseed決定的であること
- 呪い状態と呪い判明状態が別々に保持されること
- 呪われた装備は装備時に判明し、判明後は通常操作で解除・交換できないこと
- 節制が呪いのない個体や呪い未判明の個体へ誤作用せず、解呪後は解除・交換できること
- 部屋対象効果が9×7カメラ範囲ではなく部屋領域を使うこと
- 星が進行用・固定・対象外アイテムを変換しないこと
- 星がすべてのカードを変換対象・変換結果の両方から除外すること
- 星の除外後候補が0種類なら不成立、1種類ならその候補への変換が成立すること
- 月が防具だけ、太陽が武器だけを1段階強化すること
- 月・太陽の対象が装備中の1個に固定され、対象選択UIを介さないこと
- 月・太陽による強化がDPの現在値・最大値と呪い状態を変えないこと
- 月・太陽に対応する種別を何も装備していない場合、カードを消費せずターンも進めないこと
- 月・太陽が強化上限到達済みの装備中個体を対象にした場合、使用不成立となること
- 装備解除・再装備を経てもrefineLevelが保持されること
- 星による装備個体の変換で、変換後の新規個体がrefineLevel・呪い状態・呪い判明状態を引き継がないこと
- 同一seed・同一操作列で運命の輪、星、ドロップ結果が一致すること
- 既存の死亡、インベントリ、未鑑定、呪い、ターン処理を壊さないこと
- Phase 20中は17種すべてがランダム床loot候補および敵ドロップ候補から外れていること

Phase 21完了後の番号未定の独立工程で出現テーブルへ接続する際は、全17種が全階層で候補になること、カードカテゴリ→C/B/A/S→同ランク内のカード本体の順で抽選されること、C/B/A/S分布が階層で変化しないこと、カードに状態抽選が行われないこと、同一カードの複数出現が許容されることを追加検証する。

## 8. 未確定事項

以下はPhase 20の実装単位20.0c〜20.5b内、Phase 21完了後に着手する番号未定の独立工程での出現設計、またはPhase 27での最終調整時に仮値として決定する。数値は正式決定とせず、いずれもPhase 27で見直す前提の仮値として扱う。

- 皇帝の軽減率と継続ターン数（軽減の適用対象を敵攻撃のみとするか、飢餓・毒ダメージも含めるかを含む）
- 正義のダメージ式（使用者のLIFE減少量を用いる）と、減少量0（満タン時）のダメージ量、通路上での効果。敵不在時も共通仕様により使用成立とする
- 悪魔のSOL消費量、ダメージ、妨害内容、妨害継続ターン、通路上での対象、SOL不足時の成立可否。敵不在時も共通仕様により使用成立とする
- 塔のダメージ式と通路上での対象。敵不在時も使用者への効果を適用して使用成立とする
- 月・太陽による装備の強化上限（Phase 20.0cで装備個体構造を実装する際に仮値を設定する）
- 床生成装備へ呪いが付く仮確率（Phase 20.0cで設定する）
- 全17種のC/B/A/S分類とカードカテゴリ用のC/B/A/S仮weight（Phase 21完了後の番号未定の独立工程で決定する）
- カードカテゴリ全体の出現率（Phase 21完了後の番号未定の独立工程で他カテゴリと合わせて決定する）

カード固有のfloor別解禁は採用しない。永続成長系では、女教皇・女帝・戦車・力を`B`、運命の輪を`A`とする案を初期分類候補とし、残る12種と具体的weightは全17種の効果実装後にまとめて決定する。複数入手による大幅な上振れは制限対象としない。

- 節制の対象数（呪われた個体から1個、既存要素との整合は「対象選択規則」節を参照）
- 星の再抽選規則と同一アイテムの再選出可否（除外方式、「星のアイテム変換規則」節を参照）
- 月・太陽の対象範囲（装備中固定、「月・太陽の装備強化規則」節を参照）

これらを除き、カード構成と基本効果は本資料の内容で固定する。
