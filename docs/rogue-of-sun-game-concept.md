# Rogue of Sun — ゲームコンセプト

## 1. プロジェクト概要

- プロジェクト名：`rogue-of-sun`
- ジャンル：グリッド制・ターン制ローグライク
- 対象：PC向けブラウザゲーム
- ベースイメージ：『風来のシレン』シリーズのようなローグライク
- モチーフ：『ボクらの太陽』
- 雰囲気：「ボクタイのローグライクがファミコンやゲームボーイで発売されていたら」という簡素なゲーム設計
- 方針：複雑なパズル要素やリアルタイムアクションではなく、ターンごとの位置取り、探索、武器の使い分け、資源管理を中心とする
- アセット：使用許可を得たキャラクター・敵素材を利用する

## 2. 基本ゲームルール

- 見下ろし型のグリッドマップを探索する。
- プレイヤーと敵は8方向へ移動できる。
- プレイヤーが移動、攻撃、アイテム使用、待機などを行うと1ターン経過し、その後に敵も行動する。
- 斜め移動では壁の角をすり抜けられない。
- 各フロアの階段（出口）へ到達すると次のフロアへ進む。
- プレイヤーが死亡した場合、その探索を終了して最初からやり直す。
- 永続強化は設けず、その探索中に得た装備・魔法・能力はプレイ終了時にリセットする。
- アイテムを持ち帰れる仕組みを採用するかは未決定とする。

## 3. フロア進行

階段（出口）はフロア生成時点から利用可能で、フロア上に生存している敵の有無に関係なく到達すれば次のフロアへ進める。

1. フロアを探索する。
2. 階段（出口）へ到達する。
3. 次のフロアへ進む。

敵撃破・アイテム取得・カード獲得・モンスターハウス報酬などの探索行動は必須ではなく、探索を続けるか階段で切り上げるかを選ぶための任意の強化・報酬とする。

### 3.1 確定版ラン構成（Phase 23.7）

1ランは3フロアで構成する短編ローグライクとして正式に確定する。

| フロア | 位置づけ | 通常敵数 | 累積敵プール | 役割 |
|---|---|---|---|---|
| 1F | 序盤 | 6体 | 4種 | 基本操作、基礎戦闘、食料・装備・属性導線の開始 |
| 2F | 中盤 | 7体 | 8種 | 位置取り、速度差、壁抜け、予告攻撃への対応 |
| 3F | 終盤 | 8体 | 12種（全ロスター） | 高火力、突進、広範囲攻撃を含む全ロスター環境 |

- 3Fの階段へ到達すればVictory（クリア）となる。全敵撃破・鍵・ボスは要求しない。
- モンスターハウスは2F・3Fのみ出現し、各フロアで独立に20%の確率で発生する（1Fには出現しない）。
- 想定プレイ時間は20〜30分（複数部屋を探索する標準プレイ）。階段優先で進む場合は15分以内になり得る。
- 上記はいずれも現行実装済みの値であり、将来的な4F以上への拡張やボス追加は本ドキュメントの対象外とする。

## 4. 主人公

主人公はジャンゴ。

ゲーム内部では移動方向と攻撃方向を8方向で扱う。使用するキャラクター素材は4方向のため、斜め方向の行動時は内部方向を維持したまま、表示のみ上下左右の近い方向へ変換する。

## 5. 敵

使用予定の敵は以下のとおり。

- ボク
- コカトリス
- スパイダー
- コウモリ
- マミー
- ゴーレム
- ソード
- アックス
- クラーケン

色違い・バージョン違いも使用候補に含める。現時点では専用ボスを設けない。クラーケンは移動しない設置型の通常敵として扱う案がある。

## 6. 戦闘

### 素手

- 武器がなくても隣接する敵を攻撃できる。
- 敵がいる隣接マスへ移動入力すると、その場から素手で攻撃する。
- 攻撃時は敵のいるマスへ移動しない。
- 斜め方向にも攻撃できる。
- 素手は武器より弱い最低限の攻撃手段として残す。

### 武器

| 武器 | 基本特性 |
|---|---|
| 太陽銃 | 遠距離攻撃。太陽エネルギーを消費する |
| ソード | 正面1マスを攻撃する標準的な近接武器 |
| スピア | 正面2マス先まで届く |
| ハンマー | 射程は正面1マス。命中した敵をノックバックさせる |

武器は1本を持ち替えて通常攻撃する方式ではなく、最大4つの武器スロットへ登録し、対応するキーから直接使用する。

武器ごとの射程や効果の違いによって、敵との距離と位置取りに意味を持たせる。

## 7. アイテム

現時点で確定している消耗品は以下のとおり。

| アイテム | 効果 |
|---|---|
| リンゴ | HPを回復する |
| 太陽の実 | 太陽エネルギーを回復する |

武器、消耗品などはマップ上にドロップする。その他のアイテムは今後追加する。

## 8. 魔法・エンチャント

原作にある属性付与系の魔法を採用する。

- ソル
- ダーク
- フレイム
- フロスト
- クラウド
- アース

基本方針は以下のとおり。

- 最初からすべての属性を使用できるわけではない。
- ダンジョン探索中に何らかの形で入手する。
- 入手した属性は、そのプレイ中だけ使用できる。
- 武器へ一時的に属性を付与する方式を基本候補とする。
- 属性相性や状態異常の詳細は今後設計する。

## 9. 太陽システム

実物の太陽センサーは使用せず、ゲーム内時間によって太陽環境を擬似的に再現する。

- プレイヤーが行動するたびにゲーム内時間が進む。
- 当初案では24ターンを1日とし、1ターンを約1時間として扱う。
- 日照時間中は、天窓など太陽光が届く場所で太陽エネルギーを充填できる。
- 夜間は太陽光による充填ができない。
- 太陽光レベルは時間帯によって変動する。
- 太陽光レベルに応じて、チャージに必要な時間や得られるエネルギー量が変化する。
- 将来的には太陽属性の効果にも太陽光レベルを反映できる。

24ターン周期は探索に対して短い可能性があるため、1日の長さは固定せず、実際のプレイ感を基に調整する。

## 10. 操作案

| キー | 操作 |
|---|---|
| W / A / S / D | 上下左右へ移動 |
| Q / E / Z / C | 斜め方向へ移動 |
| Space | その場で待機 |
| 1〜4 | 対応する武器スロットを使用 |
| R / F / V | エンチャント関連操作 |
| Tab | インベントリを開く |

キー配置は現時点の案であり、機能追加後の競合や操作感に応じて調整する。

## 11. マップの論理構造

マップは役割ごとに次の情報へ分けて管理する。

| 区分 | 管理内容 |
|---|---|
| Terrain | 床、壁、水、穴、通行可否、日照条件などの地形 |
| Fixture | 階段、扉、罠、宝箱、天窓などの固定オブジェクト |
| Actor | 主人公、敵、商人などのキャラクター |
| Ground Item | 武器、回復アイテムなどの床上アイテム |
| Exploration State | プレイヤーが把握しているマップ情報 |

探索状態はマップ上の物体とは分離し、次の3段階で扱う。

- 未発見：表示しない
- 訪問済みだが現在は見えない：暗く表示する
- 現在視認中：通常表示する

商人のように移動しないキャラクターも、固定物ではなくActorとして扱う。

## 12. 企画上の中核

本作の基本構造は、シンプルなターン制ローグライクである。

その上で、以下の3要素を『Rogue of Sun』固有の中心要素とする。

1. ソード、スピア、ハンマー、太陽銃を同時に使い分ける武器スロット
2. 探索中に取得し、そのプレイ内で武器へ付与する属性エンチャント
3. 昼夜と太陽光レベルによって利用条件が変わる太陽エネルギー

複雑なパズルを前提とせず、通常のローグライクとして成立させたうえで、これらの要素により『ボクらの太陽』らしい探索と戦闘を表現する。
