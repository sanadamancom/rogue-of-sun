## 2. 設計基準

- 初期LIFEは15。
- 初期SOLと最大SOLも15とし、LIFEとSOLを同じ尺度の対になる資源として扱う。
- 開始時のLIFEとSOLはいずれも最大値まで満たされている。
- カラダによる最大LIFE上昇とココロによる最大SOL上昇は同じ係数を使用する。
- 3階テスト版のLv1敵による被ダメージは、防具込みでおおむね2～7を中心とする。
- 序盤敵は標準武器で1～3回、強敵は3～6回で撃破する。
- 防具を装備しても敵の攻撃は最低1ダメージとする。
- ダメージ乱数は当面追加しない。
- 武器・防具は数値だけで上位互換を作らず、射程、命中、反動、資源消費、状態異常、特効などへ性能を配分する。
- SOL・属性は有力な上乗せにするが、通常攻撃1回分を常に丸ごと追加する規模にはしない。
- 3階攻略中に能力選択が複数回発生するよう、敵数と経験値を調整する。
- バランスは単純な攻撃力ではなく、敵ごとの「必要攻撃回数」「想定被弾回数」「敵の行動頻度」で評価する。

| 命中率下限 | 5% | 10% |

仮のダメージ式:

```text
プレイヤー攻撃 = max(1, 基礎攻撃力2 + 武器威力 + 強化値 + チカラ補正 - 敵防御)
実効防御       = max(0, 防具防御力 + 防具強化値)
敵攻撃         = max(1, round(敵攻撃力 * 2 ^ (-実効防御 / 10)))
```

LIFEとSOLの基準:

```text
初期最大LIFE = 15
初期最大SOL  = 15
最大LIFE     = 15 + カラダ補正
最大SOL      = 15 + ココロ補正
```

カラダ補正とココロ補正には同じ1ポイント当たり係数を使う。装備や永続成長によって最終的な最大値が離れることは許容するが、桁と成長幅は同程度に保つ。

プレイヤーから敵への攻撃は当面固定減算を維持する。敵からプレイヤーへの攻撃だけを割合軽減へ変更し、防御10で被ダメージが概ね半分になるスケールを使う。

### 5.2 通常合成規則

- C～Aは、同じ武器種かつ同じランクの2本を合成し、ベース武器の系統に沿った次ランク1本を作る。
- 素材側は同名でなくてよい。ソードとスピアなど、異なる武器種同士は合成不可とする。
- AからSも同じ規則で、ベースにしたA武器の系統によって光側／闇側のS武器へ分岐する。
- S同士の自由なランクアップ合成は行わず、上記3つの指定ペアだけがRへ到達できる。
- 合成に使った2本は消滅する。
- 太陽銃は通常合成対象外とする。

```text
同武器種C + 同武器種C → ベース系統のB
同武器種B + 同武器種B → ベース系統のA
同武器種A + 同武器種A → ベース系統のS
指定された対のS + S → 固有R
```

Cから合成のみで作る場合、S武器1本はC武器8本相当、対になるS武器2本から作るR武器1本はC武器16本相当となる。ただし、C武器16本だけではエンドコンテンツとして軽いため、Rは通常床落ちさせず、レシピ解禁、高難度の合成場所、または終盤到達条件を別途要求する。3階テスト版ではRのデータ、レシピ、解禁条件を実装せず、Phase 24の装備・太陽鍛冶拡張で扱う。

### 5.3 攻撃力とデータ構造

武器データを以下に分離する。

```text
weaponPower
enhancement
range
accuracyModifier
solCost
traits[]
```

```text
武器威力 = weaponPower + enhancement
```

| 武器帯 | 基礎威力の目安 |
|---|---:|
| 非戦闘・特殊武器 | 0～1 |
| 標準武器 | 2 |
| 高威力武器 | 3 |
| 強力だが制約あり | 4 |
| 例外的なレア武器 | 5 |

- C～Sの通常装備の基礎威力は原則4以下とする。
- 基礎威力5は例外的なレア装備に限定する。
- 上位装備は威力だけを増やさず、属性連携、吸収、特効、射程、範囲、命中、資源消費、反動で差別化する。
- 3階テスト版で強化値を導入する場合は、原則`-1～+1`に抑える。

各ランクで必ず威力を上げるのではなく、B以降は特殊能力へ性能枠を配分する。特殊能力は原則として、条件付き追加ダメージ`+1`、種族特効`+1`、LIFE／SOL回復`+1`、通常敵の行動阻害1回程度を上限目安とする。具体的な全27種の威力・効果は、基礎戦闘値の初回実測後に確定する。

### 6.2 防御値と特殊能力の上限

- 防御10で被ダメージは概ね50%、防御12で概ね44%になる。高防御でも最低1へ直結しない。
- 防御10のスパイクメイルはSとして通常生成に残すため、1Fでも極低確率で出現し得る。防御12の黒の鎧はRとして通常床落ちさせず、長編版で低確率生成される専用封印部屋の番人撃破時に確定取得する。黒の鎧と専用部屋は3階テスト版では実装しない。
- 属性耐性は属性攻撃全体を無効化せず、属性による固定追加ダメージだけを1軽減する。
- SOL補助は消費0を常態化させない。マジックローブの20%軽減は整数環境に合わせ、消費累計による確定還元へ変換する。
- ハヤサ、敵視界、常時夜間は既存システムとの接続が必要なため、対応機能が存在しない段階では名称・データだけを先行実装しない。
- 防具は現時点では武器のようなランク合成対象にしない。15種をそれぞれ独立したドロップ・報酬候補として扱う。
- 強化値を導入する場合、3階版では原則`-1～+1`とする。長編版の上限は割合軽減式での実測後に決める。

### 7.1 Lv2・Lv3の成長枠

Lv2・Lv3は数値だけを一律倍化せず、敵ごとの行動特性も強化する。攻撃力の暫定レンジは次を上限目安とし、個別値は専用Phaseで確定する。

| 敵Lv | 通常の出現帯 | 攻撃力の全体帯 | 主な強化対象 |
|---|---|---:|---|
| Lv1 | 序盤・3階テスト版 | 4～12 | 基礎行動 |
| Lv2 | 中盤・深い階層 | 7～17 | HP、攻撃、状態異常、移動特性 |
| Lv3 | 終盤・特殊なレベルアップ | 10～23 | 追加行動、範囲、状態異常、固有能力 |

- 小型敵は攻撃上昇を抑え、回避・移動・離脱行動を強める。
- スパイダーとコカトリスは状態異常の確率・持続・予告条件を強める。
- ソードとアックスは物理攻撃力を大きく伸ばす。
- ゴーレムはHP、防御、壁役としての性能を強める。
- クラーケンは射程または攻撃範囲を強める。
- マミーは耐久と固有効果を強める。

Phase 15では通常配置をLv1に限定する。Lv2・Lv3は、敵レベル機能が実装済みならデバッグ生成でのみ検証し、未実装ならデータ設計だけを保持する。深層への直接配置、敵同士の撃破、罠などによるレベルアップ条件は後続Phaseで決める。

- ゴーレムにはハンマーが明確に有効。
- 防御持ちへ素手で挑むと極端に不利。
- クラーケンは属性または安全な遠距離攻撃を使う価値がある。
- 実際の危険度は攻撃回数だけでなく、接敵から撃破までの敵行動回数と特殊能力の回避難度を含めて評価する。

## 13. アイテム生成・供給の仮値

カテゴリごとの個数を先に確保する方式は採用しない。各階の床落ち総数を決めた後、各生成枠のカテゴリを独立した重み付き抽選で決める。

### 13.1 床落ち総数

| 1フロアの床落ち数 | 確率 |
|---:|---:|
| 2個 | 10% |
| 3個 | 25% |
| 4個 | 30% |
| 5個 | 25% |
| 6個 | 10% |

期待値は1階あたり4個、3階合計12個だが、固定数や最低数ではない。

### 13.2 カテゴリ重み

| カテゴリ | 暫定重み |
|---|---:|
| LIFE回復・食料 | 25% |
| 太陽回復 | 20% |
| 武器 | 18% |
| 防具 | 12% |
| 消耗攻撃・補助 | 20% |
| その他・希少品 | 5% |

武器・防具に当選した後は、階層別のレアリティ抽選を行う。1Fの初期値は`C 90%／B 6%／A 3%／S 1%`とし、すべての通常階でC～Sが出現可能とする。深層ほど高ランク側へ重みを寄せる。R装備は通常床落ちさせない。

- 武器、防具、LIFE回復、食料、太陽回復の出現保証を設けない。
- 一定階数出なかったカテゴリの重み上昇や、不運シードの除外を行わない。
- 3階を通じて武器や回復が一つも出ない結果、同じカテゴリに偏る結果、1FでS装備が出る結果を正常な生成として扱う。
- 悪い供給でも素手、通路戦闘、逃走、敵の分断、日向利用、資源節約などで対処できる場合を増やすが、全シードのクリア可能性は保証しない。
- マップ非連結や仕様外の完全封鎖は、難シードではなくバグとして排除する。
- インベントリ上限20は一旦維持し、実際に制約になるかを確認する。
- 合成成立率は通常の3階通しプレイだけで評価せず、供給数を増やした専用テストで検証する。
- 詳細な生成順、階層別レアリティ、救済方針、試験分類は`rogue-of-sun-item-generation-balance-draft.md`を参照する。

## 15. 初回検証の順序

1. LIFE、基礎攻撃、割合軽減式、Lv1敵HP・攻撃・防御を仮値へ合わせる。
2. 防御`0・2・4・7・10・12`について、丸め境界と最低1保証の固定テストを行う。
3. 全Lv1敵について、素手と各武器の固定戦闘テストを行う。
4. 自然回復、満腹度、消耗品、状態異常を仮値へ合わせる。
5. SOL、属性、能力成長を仮値へ合わせる。
6. 床落ち総数抽選、カテゴリ抽選、装備レアリティ抽選を分離し、確定配置と不足補正を外す。
7. アイテム生成の決定性テストと多数シードの分布テストを行う。
8. 敵数を`6・7・8体`へ増やし、Lv1のみの固定シードで3階通しテストを行う。
9. telemetryから撃破回数、被弾回数、最低LIFE、回復収支、SOL収支、アイテム欠乏率、装備レアリティ、到達レベルを評価する。
10. Lv2・Lv3をデバッグ生成できる場合だけ、防御7・10・12との組み合わせを個別テストする。
11. 結果を基に第二仮値を作り、統合前に全件テストを行う。
