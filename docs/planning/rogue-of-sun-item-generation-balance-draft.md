## 1. 結論

本作のアイテム生成は、古典的ローグライクおよび初期『トルネコの大冒険』『風来のシレン』を参考にするが、実装は固定テーブル中心の単純な方式を採用する。

1. フロアごとの床落ち総数を抽選する。
2. 各生成枠について、アイテムカテゴリを独立した重み付き抽選で決める。
3. 選ばれたカテゴリと現在階で出現可能な候補だけを取得する。
4. 候補が存在する`C / B / A / S`からレアリティを抽選する。
5. 選ばれたレアリティ内からアイテム本体を抽選する。
6. 強化値・呪い等を適用できるアイテムだけ、最後に状態を抽選する。

通常のランダム生成に参加する全アイテムは`C / B / A / S`のいずれかを持つ。レアリティはカテゴリ内の出現しやすさを管理する共通項目であり、カテゴリをまたいで直接比較・混合抽選するためには使わない。イベント品、デバッグ専用品は「貴重品」カテゴリ、レアリティなし、通常ランダム生成の対象外とする。既存のR装備は通常生成用レアリティではなく、合成や固定報酬で得る特殊な最上位装備として従来どおり別経路で扱う。Phase 22で廃止した鍵は分類・生成候補へ残さない。

所持品、直前の出現結果、能力値、連続未出現回数などを見て出現率を動的補正する仕組みは原則として採用しない。最低保証、天井、pityも設けない。一方、`floor / totalFloors`による正規化進行度から離散的な階層帯を選び、その帯の固定weightを使うことは認める。問題が実測された場合は、まず帯ごとの固定weightまたは床落ち総数を直接調整する。

カテゴリごとの最低出現数は設けない。武器、防具、回復、食料、太陽回復のいずれも、1回の冒険で一つも出ない可能性を許容する。

設計目標は「毎回公平な供給」ではなく、次の状態である。

> 良いアイテム運は攻略を大幅に楽にする。悪い供給でも知識と工夫で突破できる場合は多いが、全シードのクリア可能性は保証しない。

## 2. ゲーム全体の基準

本作は、『ボクらの太陽』を題材に、古典的ローグライクと『トルネコ』『シレン』のゲーム構造を参照する。

ローグライク三原則として、少なくとも次を維持する。

- ランダム生成ダンジョン
- プレイヤー1行動に対して敵・環境も進むターン制
- 死亡時に冒険を失い、最初からやり直す非永続的な進行

ランダム生成の偏りは排除対象ではなく、周回ごとの展開を変える中核要素とする。供給を細かく均すことで毎回同じ攻略手順へ収束させない。

## 3. 参考作品から採る構造

古典作品では、全アイテムを一つの抽選表から直接選ぶのではなく、総数、カテゴリ、個別品、追加状態を分ける方式が多い。ただし本作では、管理上必要な分離だけを採用し、補正層や例外テーブルを増やさない。

| 作品 | 生成上の参考点 |
|---|---|
| 初代Rogue | フロアの床落ち数自体が変動し、カテゴリも抽選される。食料には限定的な不足救済がある。 |
| 初代トルネコ | カテゴリ抽選後にカテゴリ内抽選を行い、強力な個別品は二段階の重みにより希少になる。 |
| SFC版シレン | 通常床、ギタン、店、特殊地形などで入手経路・テーブルを分ける。 |
| NetHack | カテゴリ抽選、個別品抽選、祝福・呪い・強化値などの状態抽選を分離する。 |

本作が採用するのは構造であり、各作品の確率や救済規則をそのまま移植するものではない。

## 4. 基本生成フロー

```text
フロア生成
└─ 床落ち総数を抽選
   └─ 各生成枠を独立処理
      ├─ カテゴリを重み付き抽選
      ├─ カテゴリと現在階から出現可能候補を取得
      ├─ 候補が存在するレアリティだけでC/B/A/Sを抽選
      ├─ 選ばれたレアリティ内からアイテム本体を抽選
      └─ 適用可能なアイテムだけ状態を抽選
```

候補が存在しないレアリティを引いた後で再抽選する方式は採らない。候補取得時点で空のレアリティを抽選対象から除外し、無限再抽選や例外的なフォールバックを作らない。

貴重品はこの通常生成フローへ参加しない。イベント、固定配置、デバッグコマンドなどの取得元から、指定された貴重品を直接生成する。デバッグ専用品の取得経路は本番環境で無効にする。

現行3Fは生成経路を検証するsampleであり、製品版の規模ではない。敵ドロップ、宝箱、店、モンスターハウス、固定報酬、専用イベントは同じカテゴリ比率を流用せず、入手経路ごとに別テーブルまたは直接報酬定義を持つ。

## 5. フロアごとの床落ち総数

現行sampleの初期案は、各階`2～6個`、期待値約4個とする。3Fでは合計平均約12個になるが、これは最大階層数や製品版総供給量の仕様ではない。

暫定的には、次の離散分布から開始できる。

| 1フロアの床落ち数 | 確率 |
|---:|---:|
| 2個 | 10% |
| 3個 | 25% |
| 4個 | 30% |
| 5個 | 25% |
| 6個 | 10% |

期待値は4個である。個数抽選はシード付きPRNGで決定し、同じシードでは同じ結果を再現する。

製品版でも1フロアの通常床落ち総数は原則として同じ分布を基準にする。最大階層数が増えればラン全体の総供給機会が増えることを意図し、3Fと同じ総数へ補正しない。モンスターハウスや固定報酬など、明確に別の入手経路だけを別扱いにする。

## 6. カテゴリ抽選

各床落ち枠について、次のカテゴリを独立抽選する。これはカード実装前に作成した初回テスト用の仮値であり、個別カテゴリの最低数ではない。Phase 21完了後に着手する番号未定の独立工程（旧20.0e）の再設計ではカードを独立カテゴリとして追加し、合計100%になるようカテゴリ比率を改めて決定する。現表の数値を維持したままカードだけを上乗せしない。

| カテゴリ | 暫定重み | 主な対象 |
|---|---:|---|
| LIFE回復・食料 | 25% | リンゴ、チョコレート、バナナ等 |
| 太陽回復 | 20% | 太陽の実等 |
| 武器 | 18% | ソード、スピア、ハンマー、太陽銃 |
| 防具 | 12% | 各種防具 |
| 消耗攻撃・補助 | 20% | 毒消し、万能薬、将来の投擲・状態異常・補助品 |
| その他・希少品 | 5% | 特殊素材、固有用途品等 |
| 合計 | 100% | — |

現行アイテム数がカテゴリ枠を満たさない場合、未実装カテゴリを別カテゴリへ均等再配分して帳尻を合わせない。Phaseごとの一時テーブルとして明示的に重みを再設定する。

武器や防具の種類数が増減しても、カテゴリ全体の出現率は変えない。個別品はカテゴリに当選した後で抽選する。

この表は通常生成カテゴリだけを扱い、貴重品は含めない。Phase 21完了後の番号未定の独立工程でカードを独立カテゴリとして加える際、「その他・希少品」を貴重品の受け皿として残さず、通常生成する具体的な品だけを割り当てる。

装備品以外のカテゴリ率とレアリティ分布は、原則として階層によらず固定する。階層進行によって出現候補またはレアリティ分布を変えるのは武器・防具だけとする。後半の回復不足などが判明した場合も、まず回復量、カテゴリweight、レアリティweight、フロア全体の配置数、敵や地形による消耗量を調整し、非装備品の階層別テーブル化は最後に検討する。

## 7. 通常アイテムのレアリティ抽選

通常のランダム生成に参加する武器、防具、食料、果実、カード、投擲物、その他の通常品は、すべて`C / B / A / S`のいずれかを持つ。カテゴリ抽選後、そのカテゴリ内で出現可能なレアリティを抽選し、さらに同レアリティ内の本体を抽選する。

同じレアリティ記号は共通データ型として使うが、weight表はカテゴリごとに持てる。たとえば武器のBとカードのBが同じ出現確率である必要はない。最初は各カテゴリにつき固定の4値だけを使い、個別アイテムweightは原則として均等にする。

### 7.1 装備の階層別レアリティ

武器または防具カテゴリに当選した場合、すべての通常階で`C・B・A・S`を抽選可能にする。低階層でも非常に低い確率で強力な装備が出現する。

`R`は通常床落ちさせない。R武器は指定された対のS武器による固有合成、R防具の黒の鎧は進行度70%以上で低確率生成される専用封印部屋の番人撃破時確定報酬とし、武器と防具で入手経路を分ける。

#### 7.1.1 現行sampleの浅層基準

| レアリティ | 浅層帯の暫定確率 |
|---|---:|
| C | 90% |
| B | 6% |
| A | 3% |
| S | 1% |
| R | 0% |

`S 1%`は床落ちアイテム全体の1%ではなく、武器または防具カテゴリに当選した後の1%である。

例えば、1階に床落ち4個、武器カテゴリ率18%の場合、S武器が1本以上出る概算確率は次のとおりである。

\[
1-(1-0.18\times0.01)^4 \approx 0.72\%
\]

武器と防具を合わせた装備カテゴリ率30%なら、S装備が一つ以上出る概算確率は約1.19%となる。

#### 7.1.2 正規化進行帯による変化

`progress = floor / totalFloors`を0～1へclampし、階層が進むほど高ランク側へ確率を寄せる。固定階番号や3F専用表は作らず、連続補間ではなく離散帯ごとの固定weightを使う。

| 正規化進行帯（暫定境界） | C | B | A | S |
|---|---:|---:|---:|---:|
| 0～30%（浅層） | 90% | 6% | 3% | 1% |
| 30～60%（中層） | 50% | 27% | 18% | 5% |
| 60～85%（深層） | 30% | 32% | 28% | 10% |
| 85～100%（最深部） | 15% | 30% | 35% | 20% |

境界とweightはPhase 24.6で実測調整する。最大階層数が増えれば、深層帯のフロア数と強い装備を得る機会が増えることを意図する。全階層数が少ない場合の特別補正、3F専用設定、最低階層数による分岐は置かない。

深層でもC装備を完全には除外しない。低ランク武器は合成素材として価値を持ち、防具は合成対象外のため、売却、投擲、交換、分解など別用途を追加する場合に価値を補う。

防具15種のC～S分類は`rogue-of-sun-zokutai-armor-selection-draft.md`の選定表を使用する。通常生成候補はC～Sの14種であり、Rの黒の鎧を通常テーブルへ混ぜない。

## 8. 個別装備の抽選

装備の抽選順は次とする。

```text
武器カテゴリ
→ レアリティ
→ 武器種（ソード／スピア／ハンマー／太陽銃）
→ 同ランク・同武器種内の個別武器
→ 強化値・呪い等
```

```text
防具カテゴリ
→ レアリティ
→ 同ランク内の個別防具
→ 強化値・呪い等
```

28種など多数の武器を床落ち全体の一つの表へ直接並べない。この分離により、武器追加後も回復品や防具の供給率が変わらず、武器種間の比率も独立して調整できる。

同じレアリティ内の個別装備は、まず均等抽選とする。プレイテストで明確な不都合が確認された場合に限り、既存の同ランク内weightを調整し、新しい補正層は追加しない。

## 8.1 カードのレアリティ抽選

カードは巻物相当の消耗品として、全17種を1階から通常床の候補にできるものとする。カード固有の解禁階層は設けず、階層が進んでも候補集合とweightを変えない。

レアリティ表記は他の通常アイテムと同じ`C / B / A / S`へ統一する。カードでは性能段階ではなく、カードカテゴリ内での出やすさを表す。各レアリティをカード用の固定weightへ対応させ、選ばれたレアリティ内のカードは原則として均等抽選する。

```text
カードカテゴリ
→ C / B / A / Sを固定weightで抽選
→ 選ばれたレアリティ内のカードを抽選
→ 状態抽選なし
```

カードを含む消耗品には、強化値や呪いなどの状態を原則として付与しない。状態が適用できないアイテムでは、生成処理の最終段階そのものを省略する。

## 8.2 貴重品

イベント品、デバッグ専用品は「貴重品」カテゴリへまとめる。貴重品は`C / B / A / S`もRも持たず、通常床、通常宝箱、通常敵ドロップなどのランダム生成テーブルへ登録しない。廃止済みの鍵は貴重品にも含めない。

```text
イベント・固定配置・デバッグコマンド
→ 取得元が指定した貴重品を直接生成
```

貴重品は通常アイテムのカテゴリ抽選、レアリティ抽選、本体抽選、状態抽選をすべて経由しない。デバッグ専用品はデバッグ専用条件でも遮断し、本番環境に取得経路を残さない。

同一カードの複数出現、永続成長カードの複数出現、run単位の出現上限は設けない。序盤に永続成長系が複数出てrun全体が大きく上振れする結果も、正常なローグライクの展開差として扱う。

永続成長系の初期分類候補は、女教皇・女帝・戦車・力を`B`、運命の輪を`A`とする。残る12種の分類、C/B/A/Sに対応する4つの基準weight、カードカテゴリ全体の割合は、全17種の効果実装後、Phase 21完了後の番号未定の独立工程で決定する。

## 9. 供給保証と救済の扱い

初回テストでは、次の救済を置かない。

- 1階の武器・防具確定配置
- 一定階数武器が出なかった場合の装備率上昇
- LIFE回復や食料の最低出現数
- 太陽の実の最低出現数
- 不足カテゴリに応じた次階の重み補正
- 不運シードの自動除外
- クリア可能性を判定した再生成

したがって、次の結果はいずれも正常な生成として扱う。

- 3階を通じて武器が一つも出ない
- 防具だけ複数出る
- 回復品または太陽の実が一つも出ない
- 同じカテゴリや同じ品が偏って出る
- 同じカードや永続成長カードが複数出る
- 永続成長カードの偏りにより能力値が大きく上振れする
- 1FでS装備が出る
- 3階合計の床落ち数が平均から大きく外れる

救済は永久に禁止するのではなく、実測により「知識、判断、立ち回りでは介入できず、特定カテゴリの抽選だけでゲームがほぼ決まる」と判明した場合に限って検討する。その場合も、供給保証より先に代替手段の不足を疑う。

## 10. 悪い供給に対するゲーム側の回答

アイテム生成を不安定にするには、すべての不足を同じ方法で補わず、複数の攻略手段を用意する必要がある。

| 不足・事故 | 想定する対処 |
|---|---|
| 武器が出ない | 素手、通路戦闘、先制、敵の分断、逃走 |
| 防具が出ない | 接触回数削減、間合い管理、先制、回復の優先使用 |
| LIFE回復が出ない | 不要戦闘の回避、日向での微回復、階段逃げ |
| 太陽の実が出ない | 日向の利用、SOL消費の抑制、非SOL行動の選択 |
| 食料が出ない | 探索範囲の短縮、階段優先、不要な往復の回避 |
| 同じ品に偏る | 投擲、合成、装備交換、将来の売却・分解等 |
| 強敵が育つ | 誘導、隔離、足止め、迂回、階段逃げ |

3階版の時点で全項目を実装する必要はないが、アイテム生成だけを不安定化し、対処手段が存在しない状態は避ける。特に素手戦闘、敵を倒さず出口へ進む経路、日向によるSOL管理は初期検証で重要となる。

## 11. 許容する不運と排除する破綻

### 許容するもの

- 極端に難しいシード
- 特定カテゴリが不足する冒険
- 強力装備により序盤が大幅に楽になる冒険
- 判断を尽くしても敗北する可能性
- 同じ攻略手順が通用しない展開差

### バグまたは設計破綻として排除するもの

- マップが非連結で出口に到達できない
- 仕様外の完全封鎖
- 必須戦闘なのに、利用可能な全手段で理論上ダメージを与えられない
- SOL必須行動しか存在しないのにSOL回復手段も代替行動もない
- 回避不能な固定ダメージだけで必ず死亡する
- 生成テーブルの設定ミスで本来出る品が永続的に出ない

「そのシードが難しい」ことと、「ゲーム規則上プレイヤーが介入できない破綻」は区別して記録する。

## 12. 現行3F sampleへの適用

Phase 15由来の現行3F sampleでは、次を回帰基準として保持する。製品版の最大階層数・総供給量・最終バランスには使用しない。

| 項目 | 初期条件 |
|---|---|
| 床落ち数 | 各階2～6個、期待値4個 |
| 3階合計 | 期待値12個。固定しない |
| カテゴリ | 各枠を独立した重み付き抽選 |
| 装備保証 | なし |
| 回復・食料保証 | なし |
| 太陽回復保証 | なし |
| 装備ランク | 全階層でC～Sを抽選可能 |
| 1Fランク | C90%／B6%／A3%／S1% |
| R装備 | 通常床落ちなし |
| 敵通常配置 | Lv1のみ |

このsampleだけでは、製品版の長期的な飢餓や合成成立率を評価できない。通常生成の試験とは別に、任意の`totalFloors`、合成、各ランク装備、欠乏状態を確認する固定テストを用意する。

### 12.1 最大階層数に依存する専用イベント

通常床落ちと別に、イベントは`progress`によるeligibilityと、対象フロアごとの独立した固定確率判定を持てる。長いダンジョンでは対象フロア数が増えるため、累積遭遇率が高くなることを意図した仕様とする。イベント固有のRNGストリームを使い、イベント追加によって地形、通常床落ち、敵配置など既存ストリームの消費順を変えない。

黒の鎧イベントの現行方針は次のとおり。

- `floor / totalFloors >= 0.70`でeligible
- 原則として最終階は除外し、取得後に使えるフロアを残す
- eligibleな各階で1回、同じ固定確率`p`を独立判定
- 1ラン最大1室。生成後は後続階で判定しない
- 通常床落ち、通常宝箱、通常敵ドロップ、通常モンスターハウス報酬と完全に分離
- 専用封印部屋の番人を倒すと黒の鎧を確定取得
- 天井、最低保証、pityなし
- `p`、最終階除外、番人、部屋構造はPhase 24.6～24.7で確定

独立判定の場合、対象フロア数を`n`とすると累積遭遇率は`1 - (1 - p)^n`となる。たとえば`p = 5%`は説明用の仮値であり、10Fの7～9Fなら約14.3%、20Fの14～19Fなら約26.5%、100Fの70～99Fなら約78.5%となる。これは確定値ではなく、長いランほど遭遇機会が増える性質の確認例である。

## 13. プレイテストの評価方針

全シードクリア率100%を目標にしない。勝率そのものより、勝敗に至るまでの判断機会と周回差を評価する。

各プレイの結果は、少なくとも次に分類する。

1. 標準的な供給で突破した。
2. 悪い供給を工夫して突破した。
3. 判断ミスまたは知識不足で失敗した。
4. 強いアイテム運により突破した。
5. プレイヤーの選択ではほぼ覆せない生成で失敗した。
6. マップ・配置・テーブルの仕様外破綻で失敗した。

`5`は一定割合を許容する。`6`はバグとして修正する。`5`が多すぎる場合も、即座に供給保証を追加せず、逃走、投擲、誘導、地形利用、資源転用などの不足を先に確認する。

## 14. telemetry

シードごと、階ごと、冒険全体について次を記録する。

- 床落ち総数
- カテゴリ別の生成数、取得数、使用数、廃棄数、最終所持数
- 全通常アイテムのカテゴリ別・レアリティ別生成数
- 武器種別・防具別の生成数
- 最初の武器、防具、LIFE回復、食料、太陽回復を取得した階とターン
- 各カテゴリが一つも生成されなかった冒険の割合
- 素手で行った攻撃回数と撃破数
- 戦闘を避けて出口へ到達した回数
- 日向回復量、SOL不足回数、飢餓到達ターン
- 死亡時のLIFE、満腹度、SOL、所持品、直前の判断
- プレイ結果分類1～6
- 1FでA・S装備を引いた回のクリア率、所要ターン、被ダメージ

平均だけでなく分布を見る。特に、カテゴリ欠乏率、床落ち総数の上下端、S装備を引いた冒険と通常冒険の差を確認する。

## 15. 調整順序

1. シード再現可能な総数抽選とカテゴリ抽選を実装する。
2. 現行sampleの仮カテゴリ重みを設定する。
3. 全通常カテゴリのレアリティ抽選を独立させる。
4. 1FでC90%／B6%／A3%／S1%を設定する。
5. カテゴリ別の確定配置と不足補正を削除する。
6. telemetryと結果分類を追加する。
7. 固定シードと多数シードの自動生成テストで、決定性と確率分布を確認する。
8. 人間による通しプレイで、悪条件下の判断機会を確認する。
9. 供給率より先に代替攻略手段の不足を修正する。
10. その後に限り、総数分布、カテゴリ重み、階層別レアリティを調整する。

## 16. 自動テスト項目

- 同じシードで床落ち数、カテゴリ、個別品、位置が一致する。
- 異なるシードで生成結果が変化する。
- 床落ち数が設定範囲外にならない。
- カテゴリ重みの合計が100%または共通の整数重み総和になる。
- 各通常カテゴリのレアリティ重みの合計が100%または共通の整数重み総和になる。
- 通常生成される全アイテムがC/B/A/Sのいずれかを持つ。
- 候補が0件のレアリティが抽選対象から除外され、再抽選を発生させない。
- カテゴリ→出現可能候補→レアリティ→本体→適用可能な状態、の順序が固定される。
- 貴重品がレアリティを持たず、通常床・通常宝箱・通常敵ドロップの候補に含まれない。
- デバッグ専用品の取得経路が本番環境で無効になる。
- 全通常階で装備のC～Sが抽選候補に含まれる。
- R装備が通常床落ちテーブルに含まれない。
- 黒の鎧が通常床落ち、通常宝箱、通常敵ドロップから生成されない。
- 最大階層数が10なら7F以降、100なら70F以降が黒の鎧イベントのeligible帯になる。
- 黒の鎧イベントが最終階で生成されず、1ランに2室以上生成されない。
- イベントRNGが同一seedで決定的であり、通常生成のRNG結果を変えない。
- 十分な試行回数で、実測分布が設定重みから許容誤差内に収まる。
- カテゴリ追加・個別装備追加で、他カテゴリの出現率が変化しない。
- アイテム配置が壁、出口、敵、プレイヤー開始地点と不正に重ならない。

確率テストでは単一シードの結果を固定期待値にせず、PRNGの決定性テストと多数試行の分布テストを分ける。
