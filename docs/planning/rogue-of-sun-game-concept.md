# Rogue of Sun — ゲームコンセプト

更新日：2026-08-17

## 1. プロジェクト概要

- プロジェクト名：`rogue-of-sun`
- ジャンル：グリッド制・ターン制ローグライク
- 対象：PC向けブラウザゲーム
- 基本システム：初代『Rogue』のアイテム分類、探索、資源管理、下降後の帰還構造を基準とする
- 独自要素：『ボクらの太陽』の太陽、属性、武器、おてんこさまをローグライクへ落とし込む
- 便利機能・追加要素：SFC版『トルネコの大冒険』『風来のシレン』を参照する
- 雰囲気：「ボクタイのローグライクがファミコンやゲームボーイで発売されていたら」という簡素なゲーム設計
- 方針：複雑なパズル要素やリアルタイムアクションではなく、ターンごとの位置取り、探索、武器の使い分け、資源管理を中心とする
- アセット：使用許可を得たキャラクター・敵素材を利用する

## 2. 基本ゲームルール

- 見下ろし型のグリッドマップを探索する。
- プレイヤーと敵は8方向へ移動できる。
- プレイヤーが移動、攻撃、アイテム使用、待機などを行うと1ターン経過し、その後に敵も行動する。
- 斜め移動では壁の角をすり抜けられない。
- 各フロアを探索し、階段へ能動的に移動して次のフロアを目指す。敵全滅や鍵取得は進行条件にしない。
- プレイヤーが死亡した場合、その探索を終了して最初からやり直す。
- 永続強化は設けず、その探索中に得た装備・魔法・能力はプレイ終了時にリセットする。
- 初期版では探索間のアイテム持ち越しを設けず、死亡・クリア時に所持品と探索中の成長をリセットする。

## 3. フロア進行

1. 1Fから26Fまで下降する。
2. 26Fで階段とは別に配置されたおてんこさまへ、成立した移動で接触して救出する。
3. 同じ26F内で階段まで戻る。
4. 再生成された25Fから1Fまで上昇する。
5. おてんこさまと地上へ帰還するとクリアする。

最大フロア訪問数は下降26回と上昇25回の計51回である。帰還時のフロアは再生成し、通常床落ちアイテムとモンスターハウスは生成しない。通常敵、敵ドロップ、罠、日照などの環境は残し、帰還を無償な消化試合にしない。

現行3Fは実装・回帰試験用のsample baselineであり、製品版の最大階層数ではない。製品設計では固定深度`depth`と下降・上昇を表す`leg`を用い、`floor / totalFloors`による正規化進行度は使用しない。

## 4. 主人公

主人公はジャンゴ。

ゲーム内部では移動方向と攻撃方向を8方向で扱う。使用するキャラクター素材は4方向のため、斜め方向の行動時は内部方向を維持したまま、表示のみ上下左右の近い方向へ変換する。

26Fで救出したおてんこさまは地上までジャンゴについてくる。原作同様、戦闘、回復、索敵、アイテム運搬などの能力は持たず、ゲーム状態上のActorではなく追従表示として扱う。

## 5. 敵

現行sampleの敵ロスターは以下の12種。

- ボク
- コカトリス
- スパイダー
- コウモリ
- マミー
- ゴーレム
- ソード
- アックス
- クラーケン
- スケルトン
- ゴースト
- ステップス

全EnemyTypeはLv1～Lv3を持つ。EnemyLevelは敵種をまたぐ絶対的な強さではなく、同じ敵系統内の段階を表す。したがって、後から登場するゴーレムLv1が、先に登場するボクLv3より強くてもよい。専用ボスは将来候補であり、26F到達や帰還の必須条件にはしない。

## 6. 戦闘

### 素手

- 武器がなくても隣接する敵を攻撃できる。
- 敵がいる隣接マスへ移動入力すると、その場から素手で攻撃する。
- 攻撃時は敵のいるマスへ移動しない。
- 斜め方向にも攻撃できる。
- 素手は武器より弱い最低限の攻撃手段として残す。

### 武器

| 武器 | 基本特性 |
|---|---|
| 太陽銃 | 遠距離攻撃。太陽エネルギーを消費する |
| ソード | 正面1マスを攻撃する標準的な近接武器 |
| スピア | 正面2マス先まで届く |
| ハンマー | 射程は正面1マス。命中した敵をノックバックさせる |

近接武器と太陽銃は装備個体として管理し、インベントリからinstance単位で装備・交換・解除する。最終的なショートカット操作はUI設計時に決める。

武器ごとの射程や効果の違いによって、敵との距離と位置取りに意味を持たせる。

## 7. アイテム

現時点で確定している消耗品は以下のとおり。

| アイテム | 効果 |
|---|---|
| リンゴ | HPを回復する |
| 太陽の実 | 太陽エネルギーを回復する |

武器、防具、消耗品、カードなどは入手経路ごとの独立テーブルから生成する。通常床落ち、通常敵ドロップ、通常モンスターハウス報酬、固定報酬、専用イベントは同じ抽選表へ混ぜない。

通常装備はC/B/Aを深度帯ごとの固定weightで生成する。武器種はソードを1F、スピアを5F、ハンマーを9Fから通常候補へ加える。S武器はA武器同士の太陽鍛冶だけで作り、R武器は指定された光側・闇側のS武器の固有合成だけで得る。S防具は下降19～26Fの通常床落ち、R防具の黒の鎧は下降19～25Fの専用封印部屋の番人撃破時確定報酬とする。

通常床落ちアイテムは下降時だけ生成する。上昇時は通常床落ちを生成しない一方、通常敵のドロップは下降・上昇の両方で発生し得る。

## 8. 魔法・エンチャント

原作にある属性付与系の魔法を採用する。

- ソル
- ダーク
- フレイム
- フロスト
- クラウド
- アース

基本方針は以下のとおり。

- 最初からすべての属性を使用できるわけではない。
- ダンジョン探索中に何らかの形で入手する。
- 入手した属性は、そのプレイ中だけ使用できる。
- 武器へ一時的に属性を付与する方式を基本候補とする。
- 属性相性や状態異常の詳細は今後設計する。

## 9. 太陽システム

実物の太陽センサーは使用せず、ゲーム内時間によって太陽環境を擬似的に再現する。

- プレイヤーが行動するたびにゲーム内時間が進む。
- 当初案では24ターンを1日とし、1ターンを約1時間として扱う。
- 日照時間中は、天窓など太陽光が届く場所で太陽エネルギーを充填できる。
- 夜間は太陽光による充填ができない。
- 太陽光レベルは時間帯によって変動する。
- 太陽光レベルに応じて、チャージに必要な時間や得られるエネルギー量が変化する。
- 将来的には太陽属性の効果にも太陽光レベルを反映できる。

24ターン周期は探索に対して短い可能性があるため、1日の長さは固定せず、実際のプレイ感を基に調整する。

## 10. 操作案

| キー | 操作 |
|---|---|
| W / A / S / D | 上下左右へ移動 |
| Q / E / Z / C | 斜め方向へ移動 |
| Space | その場で待機 |
| 1〜4 | 対応する武器スロットを使用 |
| R / F / V | エンチャント関連操作 |
| Tab | インベントリを開く |

キー配置は現時点の案であり、機能追加後の競合や操作感に応じて調整する。

## 11. マップの論理構造

マップは役割ごとに次の情報へ分けて管理する。

| 区分 | 管理内容 |
|---|---|
| Terrain | 床、壁、水、穴、通行可否、日照条件などの地形 |
| Fixture | 階段、扉、罠、宝箱、天窓などの固定オブジェクト |
| Actor | 主人公、敵、商人などのキャラクター |
| Ground Item | 武器、防具、回復アイテム、カードなどの床上アイテム |
| Exploration State | プレイヤーが把握しているマップ情報 |

探索状態はマップ上の物体とは分離し、次の3段階で扱う。

- 未発見：表示しない
- 訪問済みだが現在は見えない：暗く表示する
- 現在視認中：通常表示する

商人のように移動しないキャラクターも、固定物ではなくActorとして扱う。

## 12. 企画上の中核

本作は、初代『Rogue』を基本システムの優先参照元とする。そこへ『ボクらの太陽』を独自システムとして組み込み、ジャンル上の便利機能と追加要素に限ってSFC版『トルネコの大冒険』『風来のシレン』を参考にする。

その上で、以下の3要素を『Rogue of Sun』固有の中心要素とする。

1. ソード、スピア、ハンマー、太陽銃を同時に使い分ける武器スロット
2. 探索中に取得し、そのプレイ内で武器へ付与する属性エンチャント
3. 昼夜と太陽光レベルによって利用条件が変わる太陽エネルギー

複雑なパズルを前提とせず、通常のローグライクとして成立させたうえで、これらの要素により『ボクらの太陽』らしい探索と戦闘を表現する。
