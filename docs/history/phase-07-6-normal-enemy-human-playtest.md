# Phase 07.6 通常画面プレイテスト（人間操作）

## 方法

簡易表示や専用シミュレーターではなく、通常のゲーム画面を人間が操作して確認しました。

## 確認された事実

- 初期状態のプレイヤーはHP3、通常攻撃力1です。
- 1Fではボクとバット以外の敵への対応が基本的に厳しい状況でした。
- 通常敵をすべて1Fから混在させると、敵の特徴を評価する前に探索が終わりやすい状況でした。
- 現段階では回復、武器、恒常的な成長手段がまだ実装されていません。

## 結論

- 個々の敵をさらに弱体化する段階ではないと判断しました。
- 主な問題は、初期プレイヤーに対して全種類の敵が早期から出現することにあると判断しました。
- Phase 07の通常敵個別監査はこれで終了します。
- Phase 08では出現時期とプレイヤー成長を接続する方向へ進みます。今回（Phase 08.1）はそのうち出現時期の実装だけを行います。

## この確認で分かっていないこと

- 詳細なクリア率は測定していません。
- 各敵の遭遇回数は測定していません。
- 全敵種を十分に評価できたとは言えません（多くの回で1F突破前に終了しているため）。
